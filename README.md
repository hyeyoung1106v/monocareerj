# MONO CAREER J - starter website

This is a simple static HTML/CSS/JavaScript recreation based on the supplied screenshots.

## Run locally

Open `index.html` in a browser.

For a local development server, if Node.js is installed:

```bash
npx serve .
```

## Deploy

This folder can be deployed as a static site to Vercel, Netlify, GitHub Pages, or similar services.
